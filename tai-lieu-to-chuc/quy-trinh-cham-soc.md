# Quy trình chăm sóc khách theo mốc

> Tổ chức điền. Kỹ năng dùng tệp này để biết nên nhắn gì, vào lúc nào, và để chấm mức ưu tiên.

## Thời hạn trả lời theo mức ưu tiên
| Mức | Khi nào | Trả lời trong vòng |
|---|---|---|
| Ưu tiên 1 | Khách hỏi giá, hỏi lịch, muốn đăng ký, gửi ảnh chuyển khoản | [mặc định 30 phút trong giờ làm] |
| Ưu tiên 2 | Khách hỏi thông tin chung, khách cũ hỏi thăm | [mặc định trong ngày] |
| Ưu tiên 3 | Khách chỉ thả cảm xúc, hỏi chung chung chưa rõ nhu cầu | [mặc định trong 2 ngày] |

## Các mốc chăm sóc
| Mốc | Nhắn gì | Ai nhắn | Ghi chú |
|---|---|---|---|
| Khách mới để lại thông tin | [chào, hỏi nhu cầu] | [người được chia khách] | |
| Khách đăng ký lớp hoặc webinar | [xác nhận, gửi lịch, nhắc trước buổi] | | |
| Khách đã chuyển khoản | [xác nhận đã nhận, hướng dẫn vào lớp] | | Kế toán xác thực thanh toán |
| Trước buổi học | [nhắc giờ, đường vào lớp] | | |
| Sau buổi học | [hỏi cảm nhận, giải đáp] | | |
| Học viên vắng buổi | [hỏi thăm, gửi tài liệu bù] | | |
| Kết thúc khóa | [xin cảm nhận, mời khóa nối tiếp] | | |
| Khách cũ lâu không tương tác | [hỏi thăm, giới thiệu nội dung mới] | | Tối đa [số lần] |
